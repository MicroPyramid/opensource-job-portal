# User Guides

For people using a PeelJobs site rather than running one.

- **[Job Seekers](job-seekers.md)** — searching, applying, alerts
- **[Recruiters](recruiters.md)** — posting jobs, managing applicants, team
- **[Administrators](administrators.md)** — moderation and platform operations

These describe the software as built. A given deployment may have features
disabled or branding changed — most visibly, **email notifications depend on
background jobs that are disabled by default**. See
[Background Jobs](../architecture/background-jobs.md).

URLs below are relative to the site you are using.
